# 2026-11-08 — Interface languages, brewing tools, and roadmap fixes

## Interface languages

- Added English and Norwegian Bokmål interface language selection, including
  first-login and settings controls. Preferences are stored locally and saved
  per account; backup restore refreshes the selected language.
- Added Norwegian translations across the application, including Brewing
  Academy questions, guides, calculators, and registered user-facing errors.
  Admin screens and user-generated content remain outside the translation scope.
- Added translated, parameterized Academy math questions and preserved English
  question identifiers for existing learning progress. Registered known API
  errors for translation while leaving unknown diagnostics visible.
- Reviewed Norwegian wording and adjusted brewing terminology, retaining
  OG, SG, and FG and using parti for batch references.
- Guarded first-login preference saving against account changes and applied
  the selected preferences only after the save succeeds.
- Apply `20261105204500_add_preferred_language.sql` before deploying the
  language preference changes.

## Brewing calculators

- Added a bottle-count calculator that estimates full bottles and leftover
  volume from the available liquid and bottle fill size.
- Organized calculators into expandable sections with consistent controls and
  descriptions.

## Roadmap and navigation

- Added a shortcut from admin feedback to the roadmap and a form for adding
  roadmap items directly to the planned column.
- Made the roadmap Back button retain its originating admin or feedback page
  when items are created or moved. Direct visits default to the admin page.

## Interface fixes

- Refreshed active-batch notes after saving so new notes can appear without
  leaving and reopening the vessel; added visible save and refresh errors.
- Replaced the shared expand arrow with an SVG that points right when
  collapsed and turns down when expanded, avoiding emoji rendering.
- Made account deletion show password-verification and deletion failures and
  prevent duplicate submissions while deletion is in progress.
- Improved recipe creation failure handling so failed saves show an error
  instead of leaving users without feedback.
- Updated sign-in error handling to distinguish registered authentication
  errors rather than treating every provider error as incorrect credentials.
- Set a minimum 16px font size on mobile text fields, textareas, and selects
  to reduce focus zoom without disabling manual zoom. The roadmap text field
  was checked at a mobile viewport; real iPhone Safari verification remains
  outstanding.
