# 2026-11-09 — Brewing mix charts and 2.5.0 release

## Brewing mix on profiles

- Added a "Brewing mix" section to public member profiles and to My Account
  with two donut charts: one for batches and one for recipes. Segments show
  only percentages (rounded with the largest-remainder method so they total
  100%), each labelled inside its own segment, with per-drink colours and a
  hover highlight.
- Batch percentages count all of the user's batches, including private ones;
  no counts are exposed. Recipe percentages count only public recipes for
  visitors, and all recipes for the owner. A chart is hidden when it has no data.
- `/api/community/profile` now returns `brewMix` and `recipeMix`. Shared logic
  is in `lib/brewing/brewMix.ts`; the chart is `app/components/BrewMixChart.tsx`.
  No database migration is required.

## Norwegian terminology

- Norwegian now uses "Batch"/"Batcher" instead of "Parti"/"Partier" for brewing
  batches, and "Gjær" for yeast labels. The localization tests cover both.

## Release

- Bumped the application, Tauri package, Cargo crate, and Tauri config from
  2.3.6 to 2.5.0.

## Verification

- The localization suite passed (22 tests); TypeScript and ESLint on the new
  files passed. The charts were checked in the browser on My Account; the
  public profile page was not re-checked after the recipe chart was added.
